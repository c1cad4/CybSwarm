# CybSwarm

Координация и выполнение задач группами агентов

## Реализовано

Детерминированная координация 1–8 зарегистрированных агентов. Все capabilities проверяются до начала записи. Транзакционная гарантия распространяется на локальную SQLite память; внешние side effects в эту версию не входят.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```
